# SOciaLink - Next-Gen Social Networking Platform

Web app accessible at: **http://localhost/SOciaLink/**

### Technology Stack
- PHP 8 (MVC architecture, PDO prepared statements)
- MySQL (`social_app` database)
- Bootstrap 5.3 + Bootstrap Icons + Custom Design System
- Vanilla JavaScript (AJAX likes, reactions tray, chat dock, modals, dark mode)

### Quick Start
1. Start **Apache** and **MySQL** in XAMPP.
2. Open your browser to: `http://localhost/SOciaLink/`
3. Log in with demo accounts: `maria` / `juan` / `ana` (password: `password123`) or register.
